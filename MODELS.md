# AI Models

## OpenRouter Qwen3 Coder 480B
Use this as the Architect and Main Builder.

- all feature implementation
- multi-file edits
- domain modeling
- SvelteKit structure

## Groq Qwen3 32B
Use this as the Fast Coder / Iterator.

Use for:
- quick features
- UI tweaks
- bug fixes
- "try this idea"

## Open Router GPT-OSS 120B
Use as the Backup Brain.

Use for:
- fallback when others fail
- second opinions
- debugging weird issues
